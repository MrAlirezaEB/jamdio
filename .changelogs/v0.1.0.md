# v0.1.0 — Fix track upload, realtime broadcasting, and Icecast streaming

**Date:** 2026-06-29

## Summary

Fixed the full guest-upload-to-stream pipeline, which was broken at three
independent points: a 500 error when submitting a track, broadcasts never
reaching the browser, and Icecast crash-looping so nothing streamed.

## Fixed

- **Track upload crashed with a `TypeError` (`Grammar::parameterize(): ... int
  given`).** The `QueueUpdated` event exposed a `public array $queue` property.
  Laravel's broadcast dispatcher reads `$event->queue` to choose the *queue
  name*, so it tried to push the broadcast job onto a queue named after the
  track-list array, blowing up the `jobs` table insert. Renamed the property to
  `$tracks`; `broadcastWith()` still emits the `queue` key, so the WebSocket
  payload and the frontend listeners are unchanged.
- **Realtime updates never reached clients** (queue stayed empty in the UI after
  an upload). The server-side broadcaster pushed events to
  `REVERB_HOST=localhost`, but inside the `app`/`worker` containers `localhost`
  is not the Reverb container. Split the host: the browser still uses
  `REVERB_HOST`, while server-side pushes use a new `REVERB_PUSH_HOST` (Docker
  service name `reverb`), falling back to `REVERB_HOST` when unset.
- **Nothing streamed** — the Icecast container was crash-looping (`Exited (1)`)
  because icecast2 refuses to run as root and the config had no `<changeowner>`
  directive. With Icecast down, Liquidsoap could not connect to `/stream`
  (`Connection failed: Not_found`) yet kept advancing the DB queue at every
  track boundary, silently draining uploaded tracks to `played`. Added a
  `<changeowner>` directive so Icecast drops to the unprivileged `icecast` user
  after binding the port.

## Changed

- Documented the broadcasting/streaming topology: `README.md` now explains that
  the `worker` container must run for realtime, and why the two Reverb hosts are
  split. `.env.example` gains the `REVERB_PUSH_HOST` knob.

## Files touched

- `app/Events/QueueUpdated.php` — renamed `$queue` property to `$tracks` to avoid
  colliding with Laravel's broadcast queue-name resolution.
- `config/broadcasting.php` — reverb connection `options.host` now reads
  `REVERB_PUSH_HOST` (falls back to `REVERB_HOST`).
- `docker/icecast/icecast.xml.template` — added `<changeowner>` so Icecast can
  start without running as root.
- `.env.example` — added `REVERB_PUSH_HOST=reverb`.
- `README.md` — documented worker requirement and the split Reverb hosts.
